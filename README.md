# dsh-fish-diary

给角色一个**永不衰减的日记本**：原文单独存成 `.md`，不进记忆衰减池；记忆里只留一行带日期的索引。

## 效果

- **写日记**：角色调 `diary_write`，原文存成 `<DSH_HOME>/fish-diary/YYYY-MM-DD.md`，一天一篇、永不删；
- **读日记**：调 `diary_read`，给日期读那天，不给日期默认最近一篇；
- **索引**：写完后角色调 `remember` 记一行「YYYY-MM-DD 日记已写」（tags: 日记、日期），这样检索才找得到。

## 关键设计（和阿鱼一起定的）

| 规则 | 说明 |
|---|---|
| 一天一篇 | 同一天再写 = **续写**（追加，中间留 `—— HH:MM ——` 分隔）；传 `rewrite=true` 才是重写 |
| 生活日 | 日期用「早上 6 点起算」的生活日，凌晨 0–6 点写的归前一天，和过日子插件同口径 |
| 原文不衰减 | 存的是**那一刻的原文**，不进 fish-memory 的衰减池；记忆里只有一行索引 |
| 读写各一个工具 | `diary_write` / `diary_read`，角色自己能写能读 |

## 状态文件

日记原文就在这个目录，纯 `.md` 文本，**你（主人）随时能双击打开看**：

```
<DSH_HOME>/fish-diary/
  2026-11-16.md
  2026-11-17.md
  ...
```

## 安装

跟 `dsh-life-state` 一样：

1. 把整个 `dsh-fish-diary` 文件夹推到你的 GitHub 仓库；
2. DSH → 插件 → 添加插件 → 粘贴 `https://github.com/<你的用户名>/dsh-fish-diary` → 安装；
3. 完整退出 DSH 重开。

## 说明

- 工具是**全局注册**的（所有会话都看得见），但日记目录是全局一份；
- 索引（记忆里那一行）**由角色自己调 remember 记**，本插件只管文件读写——这样两套东西（记忆的衰减池 / 日记的永久原文）各归各，不互相污染。
